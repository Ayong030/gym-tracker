# Gym Progress & Body Tracker

Aplikasi web modern untuk mencatat progres gym, foto bentuk tubuh (Front, Side, Back), berat badan, dan persentase lemak tubuh (dilengkapi kalkulator Navy Method). Mendukung bahasa Indonesia dan Inggris secara instan.

## Fitur Utama
- **Pengisian Fleksibel:** Hanya Tanggal yang wajib diisi; berat, lemak tubuh, foto, dan catatan bersifat opsional.
- **Dwi-Bahasa:** Beralih instan antara Bahasa Indonesia dan English (EN/ID).
- **Kalkulator Navy Body Fat:** Estimasi persentase lemak tubuh berdasarkan jenis kelamin dan ukuran lingkar tubuh.
- **Perbandingan Foto Side-by-Side:** Bandingkan foto progres dari dua tanggal berbeda dengan perhitungan selisih berat badan.
- **Analitik Chart.js:** Grafik interaktif tren berat badan dan lemak tubuh dari waktu ke waktu.
- **Backup Data Lokal:** Ekspor dan Impor data dalam format JSON.

## Cara Menjalankan
1. Clone atau unduh repositori ini.
2. Buka file `index.html` langsung di browser Anda.
